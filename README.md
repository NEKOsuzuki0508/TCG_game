# 売ってないTCG — 新カード効果修正版

## 公開構成

GitHub Pagesのリポジトリ直下へ、公開用ZIPのファイルとフォルダを配置してください。`index.html` だけでは動作しません。

## 今回の修正

- No.1000〜1035のカードデータを「調整版36人・磁気波動全炸裂」データへ統一しました。
- 効果処理側のID対応（No.1000=ミヤ、1001=フランカ、1002=ルネ…）とカード名・特性・技を一致させました。
- 旧IDに残っていた攻撃補正、開幕装甲、反撃追撃などの旧効果が、新しい特性と重複して発動しないように整理しました。
- 磁気波動の超過ダメージ、フランカの+5補正、ルネの技による追加付与、行動終了時の全枚数炸裂と連鎖・回復誘発を修正しました。
- 燃焼の追加ダメージ・回復は、燃焼を付与した瞬間ではなく、対象の行動直前に燃焼が発動したときに処理するようにしました。
- 旧版の進行中対戦が復元されて旧効果を再表示しないよう、対戦状態の保存キーを `tcg_vivid_state_v2` に変更しました。
- 公式カード No.1〜91、アカウント接続先、編成・デッキの保存キーは変更していません。

## 更新後の注意

公開反映後はブラウザを強制再読み込みし、新しい対戦を開始してください。旧版の進行中の対戦は引き継がれません。保存済み編成はIDを保持しますが、No.1000〜1035は今回の調整版データのカードに対応します。

## データ出典

- 公式カード No.1〜91: 既存の `基本ルールとカードリスト2.txt` 由来データを維持
- 非公式カード No.1000〜1035: `編成(調整).docx` の調整版と、プロジェクト内の `TCG_調整版_36人_磁気波動全炸裂.json`

## 検証上の制約

- 複雑な効果の一部は手動裁定UIを使用します。全効果の完全自動化を保証するものではありません。
- 自動テストはカードID・技処理36件・磁気波動・旧効果の混入防止、および既存の対戦UI回帰テストを対象としています。
- GitHubへのコミット・公開はこのパッケージ作成では実施していません。
