# 売ってないTCG — 表記整理・著作権表記対応版

## 公開構成

GitHub Pagesのリポジトリ直下へ、公開用ZIPのファイルとフォルダを配置してください。`index.html` だけでは動作しません。

## 今回の更新

- 画面見出し・カード分類・説明文を整理し、ブランド名や区分に関する不要な表示を削除しました。
- フッターに権利表記を追加しました。
- カスタム編成のキャラクター選択／選択解除で、ページ・モーダル・一覧のスクロール位置が維持されます。
- AIの攻撃対象選択を調整し、敵単体を狙う技が自分側のキャラクターを対象にしないようにしました。
- 手札ソートは「引いた順・種類別・MP順」で昇順／降順を選択できます。
- 保存済み対戦を復元する際、カードIDに対応するキャラクター名へ同期します。名前の不一致が疑われる古いログは表示対象から外します。
- No.1000〜1035のカードデータと技処理の対応を統一し、旧版効果との重複を整理しました。
- 磁気波動の超過ダメージ、補正、追加付与、連鎖・回復誘発、燃焼の処理タイミングを調整しました。
- 対戦状態の保存キーは `tcg_vivid_state_v2` です。以前の対戦途中の状態は引き継がれませんが、編成・デッキ・アカウントの保存キーは変更していません。

## データ構成

- 基本カード No.1〜91: 既存のカード資料を基にしたデータ
- 追加カード No.1000〜1035: 調整版36キャラクターのデータ
- ユーザー登録カード: ブラウザ上で追加・編集可能
