# 売ってないTCG — 追加カード端末間同期版

## 公開方法

`20261030_追加カード端末間同期_GitHubPages用.zip` の中身を GitHub Pages の公開リポジトリ直下へ配置してください。`index.html` だけでは動作しません。`config.js` の既存Cloudflare Worker URLは維持しています。

## 今回の変更

- アカウント新規登録時に、登録した端末の追加カード・編成・デッキ・チーム設定をクラウドへ初回保存します。
- 同じアカウントで別端末からログインしたとき、その端末にユーザー保存データがなければ、クラウド上の追加カード・編成・デッキを自動で復元します。
- 追加カードの登録・編集・削除は、同期準備完了後にクラウドへ自動保存します。
- 端末ごとに前回同期した内容の指紋を保存し、別端末で更新されていた場合は、この端末に未同期の変更がなければ自動取得します。
- この端末だけに未同期の変更があり、クラウド側が前回同期内容のままなら、この端末の変更を自動アップロードします。
- 両方の端末で同時に変更されている場合は、自動上書きせず競合として保護します。
- クラウドに別の保存内容がある場合、ローカルデータを無断で上書きしません。追加カードはカード管理画面の「JSONでバックアップ」で保存してから取得できます。
- 既存のCloudflare Worker API・D1スキーマは変更していません。フロントエンドの更新のみで利用できます。
- 指定の著作権表記を維持し、旧ブランド表記・免責表記の残存を確認します。
- 既存の対戦効果、AI対象選択、ログ名、手札ソート、カスタム編成スクロール、アカウント機能を引き継ぎます。

## 端末間で使う手順

1. 追加カードを登録する端末でアカウントにログインします。新規登録時は、その端末のカードを含むデータが初回クラウド保存されます。
2. 同じアカウントで別端末にログインします。別端末に保存データがなければ、追加カードを含むクラウドデータが自動で読み込まれます。
3. 同期完了後は、追加カードの登録・編集・削除が自動保存されます。
4. 既に利用している端末では、前回同期後に別端末だけで更新された内容を自動取得します。両端末に未同期の変更がある場合は自動上書きしません。必要な追加カードをJSONでバックアップしてから、アカウント画面の「クラウドから取得」を選んでください。
