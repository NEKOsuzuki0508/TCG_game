20261030_追加カード端末間同期 差分パッチ

適用先：20261029_アカウント機能復旧 版

1. ZIP内の assets/js/account.js を、公開リポジトリ内の同じパスへ上書きしてください。
2. GitHub Pagesの公開後、ブラウザを強制再読み込みしてください。
3. Cloudflare Worker・D1スキーマの変更は不要です。既存の config.js と Worker URL をそのまま使用します。

動作：
- アカウント新規登録時、この端末に登録済みの追加カードを含むデータをクラウドへ初回保存します。
- 別端末で同じアカウントにログインし、ローカル保存データがない場合は、クラウド上の追加カード・編成・デッキを自動復元します。
- 同期済み端末で追加カードを登録・編集・削除すると自動保存します。
- 前回同期後に別端末だけで更新された場合は、未同期のローカル変更がなければ自動取得します。ローカルだけに変更がある場合は自動アップロードします。両端末に変更がある場合は自動上書きしません。必要な追加カードは「カード管理」からJSONでバックアップしてからクラウド取得を行ってください。

端末間共有は同じアカウント内です。全ユーザー共通のカード公開機能ではありません。
GitHubへの反映はこのZIP作成では実施していません。
